PARCEL TRACKING SYSTEM - JAVA SWING
===================================

Requirements
------------
1. Install JDK 21 (JDK 17 or later should also work).
2. Install Visual Studio Code.
3. In VS Code, install "Extension Pack for Java" by Microsoft.

Run in VS Code
--------------
1. Extract this ZIP file.
2. Open the extracted ParcelTrackingSystem_JavaSwing folder in VS Code.
3. Open src/ParcelTrackingSystem.java.
4. Click Run above the main() method.

Run using Terminal
------------------
Open the project folder in the VS Code terminal and run:

    javac -d out src/ParcelTrackingSystem.java
    java -cp out ParcelTrackingSystem

Modules included
----------------
1. User Management
2. Parcel Registration
3. Delivery Management
4. Parcel Management (search and delete)
5. Report and History
6. Dashboard

Important
---------
This is a starter implementation based on the module headings supplied in the
contents-page image. It uses Java Swing only (no HTML/CSS/JavaScript and no
external database). Data is held in memory and resets when the application
closes. Upload your detailed module pages/screenshots if you want the exact
module workflow and screens matched to your report.
